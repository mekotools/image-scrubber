# mekotools/image-scrubber

**Öffentliches Spiegel-Repo des MekoTools-Katalogs.** Enthält keine eigene
Software: veröffentlicht wird das fertige Container-Abbild, damit es **ohne
Anmeldung** gezogen werden kann.

- Werkzeug: Foto-Anonymisierer auf Basis von Image Scrubber
  (`everestpipkin/image-scrubber`, MIT)
- Bezug: `docker pull ghcr.io/mekotools/image-scrubber:latest`
- Bauvorschrift: interne GitLab-Instanz, `tilllt/mekotools/mekotools-image-scrubber-390b166c`
